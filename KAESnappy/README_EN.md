
# KAESnappy User Guide

## Overview

The KAESnappy algorithm integrates the compression API (snappy_compress) in the open-source Snappy. It uses hardware-based computing to offload the Lz77 algorithm in the original compression process to optimize performance. The compression API has no restriction on the size of the data to be compressed. It can be used in the same way as the open-source Snappy compression algorithm.

### Features

* **Hardware-based acceleration**: The hardware accelerator boosts compression speed, while the API enhances compression task efficiency and reduces CPU load.
* **Snappy compatibility**: The compressed data generated by the API is compatible with the Snappy format used in the community.
* **Easy integration**: You can easily implement high-performance data compression by dynamically linking the KAESnappy dynamic library. No modification to the open-source Snappy API is required, allowing for seamless integration into existing applications.

## Background Dependencies and Installation and Compilation Description

This algorithm is part of KAE 2.0. For details about the hardware environment and OS restrictions, see KAE Installation Preparations.

To use this API, you need to correctly install KAE 2.0. You are advised to install the latest KAE version using the source code.

* Notes:
  Run the following command to install the development kit on which KAE depends:

```
yum install -y make kernel-devel libtool numactl-devel openssl-devel lz4-devel libzstd-devel chrpath
```

### Compilation and Usage

After installing KAE 2.0, install KAESnappy in the KAE 2.0 directory.

  ~~~
  sh build.sh snappy
  ~~~

Then, use **LD_LIBRARY_PATH** to specify the path of the dependency library so that the application can link to the KAESnappy dynamic library. Run the ldd command to check whether the linking is successful. For details, see the [Installation Guide](../docs/en/installation_guide.md).
